# Security Policy

## Reporting a vulnerability

If you find a security issue in the `ticketing` contract (an
authorization bypass, an integer overflow path, a way to mint or
transfer a ticket without the correct signer, etc.), please do not
open a public issue. Instead, contact the maintainers privately
through the StellarTickets GitHub organization.

## Scope

This contract has not had a third-party audit yet. Treat it as
testnet-only until one has been completed.
